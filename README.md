# Pi Kiro Headless

Pi extension that registers a `kiro_headless` tool for delegating tasks to Kiro CLI without interactive prompts.

## Install locally

```bash
pi -e ./src/index.ts
```

## Install from Git

```bash
pi install git:github.com/YOUR_USER/pi-kiro-headless
```

Set `KIRO_CLI_PATH` if Kiro is not installed at `~/.local/bin/kiro-cli-chat`.
